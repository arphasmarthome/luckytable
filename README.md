# Lucky Table 日历机交互原型评审包

版本日期：2026-09-10。画布：1920 × 1080（16:9）。

## Expo 版本（2026-09-14 起）

整套原型已改以 **Expo（React Native + Expo Router）** 重建，程式碼在 `expo-app/`，可在手機與平板 / 桌面瀏覽器以響應式版面操作，並以靜態網頁形式部署到 Vercel：

- 本機執行：`cd expo-app && npm install && npm run web`（http://localhost:8081）。
- Vercel：專案根目錄的 `vercel.json` 會安裝並建置 `expo-app/`（`npx expo export --platform web`），輸出 `expo-app/dist`；舊的 HTML 原型仍會一併複製，可在 `/prototype/device/index.html` 開啟對照。
- 說明見 `expo-app/README.md`。以下「打开方式」與功能說明針對舊的 HTML 原型（`prototype/`），仍可直接開啟對照。

## 打开方式

1. 将整个 ZIP 解压到一个文件夹，不要直接在压缩包内打开 HTML。
2. 双击本文件旁的 `index.html`，使用最新版 Microsoft Edge 或 Google Chrome 打开。
3. 页面会进入日历机首页。建议使用横向大屏，浏览器缩放为 100%；窗口变化时画布等比缩放，四周留白是正常现象。

无需联网、安装依赖、启动服务器或登录。请保留完整目录结构，不要单独移动 HTML。无法通过入口跳转时，直接打开 `prototype/device/index.html`。

## 界面语言

设置 → 显示与语言 → 语言，可在 繁體中文 / English / Deutsch / Español 之间切换。切换后整机（首页、行事历、积分、健康、设置，以及嵌入的做菜与相框）都会即时改用所选语言，包含日期、星期与数字格式；语言选择保存在浏览器中，刷新后仍然沿用。也可在网址加上 `?lang=en`、`?lang=de` 或 `?lang=es` 直接以指定语言打开。

翻译字典位于 `prototype/device/i18n.en.js`、`i18n.de.js`、`i18n.es.js`；程序中的繁体中文字符串即为字典键，未翻译的字符串会直接显示原文。

## 评审范围

导航顺序：首页 → 食谱 → 健康 → 行事历 → 积分 → 相框 → 设定。

所有业务功能与当前原型保持一致。本包暂时关闭“交互 / 评论”辅助模式，所有按钮用于正常操作；侧栏与弹窗不再显示模式切换。

建议检查以下流程：

- 首页选择用餐成员，进入「做菜」；拍摄食材 → 核对数量 → 我能做什么 / 我想做 → 料理详情（加入今晚、开始料理）→ 料理画面（左侧 1/2/3 切换料理、逐步计时、顶部所有料理剩余时间、左上分割画面同时做两道菜）。今晚的料理选择会被记住。
- 「做菜」右上角的「食谱」按钮列出全部料理并依库存排序；详情如 `prototype/make/README.md`。
- 行事历切换年/月/周/日视图；新增、编辑、删除行程；选择人物，输入语音转写示例，核对后保存。
- 积分中管理任务、打卡、兑换奖励，以及查看成长记录、账本和饮食资料。
- 健康中切换成员、编辑资料、查看家庭活动与健康料理。
- 相框切换照片、使用角落 AI 按钮；从设定进入照片管理、上传与动态偏好。
- 设定中的网络、手机、同步、显示、提醒和相框设置。

## 2026-09-14 更新：食谱 → 做菜（Make）

- 左侧导航的「食谱」分类已由新的 `prototype/make/` 模块取代并更名为「做菜 / Make」，架构与交互来自 Lucky Table prototype setup 套件（Make + Recipes），视觉参考 calendar-device 主题（白色面板、橘色主色、放大的字级）。
- 料理照片与原始食谱由 TheMealDB 在线载入（离线时以底纹与内建步骤代替），这是新模块唯一需要联网的部分。
- 旧的 `prototype/recipe/` 目录不再被整机引用，仅保留供对照，可删除。

## 2026-09-14 第二轮更新

- 首页：移除大照片与月历，改为四张卡片——「今晚的菜色」（来自做菜模块，含照片、时间、掌厨与备料状态）、「家人 · 今晚一起吃」（每位成员 是 / 否）、「大家的投票」、「今天的安排」。

## 演示边界

- 本包是前端交互原型，不是正式产品；页面刷新后，整机内的修改重置。
- 人物语音使用手动输入的转写示例，不调用录音或服务器语音模型。
- 手机上传、食材识别、相框五秒画内动态为本机演示，不连接手机上传服务或真实 AI，不向服务器提交照片。
- 同步、Wi-Fi、设备绑定、更新、通知等为演示，不修改电脑系统或产生真实通知。
- 健康数值仅供流程演示，不用于诊断；过敏与忌口需人工核对。
- 包内图片仅供本次原型评审，正式产品仍需确认素材授权与清晰度。

详细功能及实现边界见 `prototype/device/README.md`。本包包含全部运行资源和图标许可证，未包含原始设计图、历史方案、测试截图或工作区中的其他文档。
