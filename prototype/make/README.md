# Lucky Table · Make（做菜）模組

取代原本的「食譜」分類。架構與互動來自 **Lucky Table prototype setup** 套件（`Lucky Table.dc.html`）的 Make 與 Recipes 兩個區塊，整合成整機左側導覽中的單一「做菜 / Make」分類。

## 開啟方式

- 整機：開啟 `prototype/device/index.html#make`（舊連結 `#recipe` 會自動轉到 `#make`）。
- 單獨檢視：直接開啟 `prototype/make/index.html`，右上角可切換 EN / 繁中；加上 `?lang=en` 可指定語言。

## 2026-09-14 第二輪更新

- **食譜目錄**：改用 Lucky Table 參考版（luckytablev1.vercel.app）的完整 TheMealDB 目錄，共 134 道料理（`dishes.js`），含中文名稱、分類篩選（快炒、丼飯、小菜、牛肉、雞肉、豬肉、羊肉、山羊肉、海鮮、義大利麵、甜點、早餐、前菜、蔬食、純素、其他）與預估時間；照片來自 TheMealDB。原始食譜與步驟在開啟料理或開始料理時才向 TheMealDB 載入並快取。
- **今晚的餐桌**：每道菜旁有 × 可直接移除；顯示每道菜的備料狀態。
- **開始料理的條件**：料理詳情與今晚餐桌的「開始料理」只有在食材備妥 100% 時才能按下（缺料時顯示原因）；已勾選「買到了」的食材會被記住。
- **食譜步驟只在料理畫面顯示**：料理詳情不再於照片下方列出作法，按「開始料理」後才進入逐步料理畫面。
- **計時**：按「開始」後該道菜的步驟會一步接一步自動倒數（上一步到 0 自動開始下一步）；頂部新增「全部開始 / 全部暫停」可同時啟動所有料理的當前步驟。
- **庫存份量欄**：新增「份量」欄（每單位的重量或容量），依整機「設定 → 顯示與語言 → 度量單位」以公制（g / kg / ml / L）或英制（oz / lb / fl oz）顯示；單獨開啟時右上角可切換。

## 畫面

| 畫面 | 內容 |
| --- | --- |
| Make 首頁 | 「今晚的餐桌」條（今晚選好的料理、用餐人數、預估剩餘時間、開始料理）＋ 三個入口：**我能做什麼？**（拍攝食材）、**我想做…**（選菜）、**分享** |
| Recipes（食譜） | 每個畫面右上角固定的「食譜」按鈕；所有料理依庫存吻合度排序 |
| Capture → Review | 模擬相機逐張辨識，核對數量後加入庫存，或直接比對「這次拍到的」/「家中全部食材」 |
| What can I make / I want to make | 料理卡片（吻合度／缺料），分類篩選 |
| Dish detail | 料理照片、家人投票、**加入今晚**、安排到行事曆、**開始料理**、食材備妥度與缺料加入採買清單、原始食譜（TheMealDB） |
| What's in stock | 庫存數量調整，向左滑動刪除 |
| Share | 分享菜色、代買清單（購物車內容，可複製）、開啟行事曆 |
| Cooking（料理中） | 見下 |

## 料理畫面（依白板設計）

- 最上方：**所有料理剩餘時間**（今晚所有料理未完成步驟的計時總和）與進度條。
- 左側：料理切換 **1 / 2 / 3 …** 與「＋」新增料理；中間：料理照片（1:1）與計時控制（開始／暫停、+1 分鐘、重設、完成）。
- 右側：編號步驟清單，每一步右側有自己的計時器；目前步驟以淡黃色標示。點步驟可切換，計時到 0 自動標記完成並跳到下一步。
- 左上角 **分割畫面** 圖示：A ｜ B 兩道料理並排，各自的計時器覆蓋在照片上，步驟清單在照片下方。每側上方的 1 / 2 / 3 可各自選擇料理。
- 今晚的料理選擇與料理進度存於 `localStorage`（`luckytable-make-tonight`、`luckytable-make-cook`，以日期為界），切換模組或重新整理都會保留；計時以到期時間計算，離開畫面仍持續倒數。

## 視覺

色彩與字級參考 `calendar-device-hzlb.vercel.app`：白色面板、橘色主色 `#f38347`、灰色分隔線、圓角 8–20 px；字級放大（內文 18、卡片 20、區塊標題 24、頁面標題 32、計時 48–56）。所有值集中在 `styles.css` 的 `:root` 變數。

## 資料與邊界

- 料理、食材、庫存、拍攝示例與圖片來源沿用原型套件：料理與食材照片、原始食譜由 **TheMealDB**（免費、免金鑰）載入並快取於 `localStorage`；離線時照片以底紋代替，步驟改用內建的逐步料理版本。
- 每道料理的逐步計時（`STEPS`）為原型示範值，正式版應由食譜資料提供。
- 與整機的訊息橋接沿用 `lumiq-device` channel：`ready`、`snapshot`（畫面、購物車、今晚料理、剩餘時間）、`meal`（開始料理時回報菜名）、`navigate`；整機傳入 `activate`（`screen: home | recipes | cook`、`action: cart`）、`deactivate`、`context`（語言、成員、用餐成員）。
- 語言：整機四種語言中，繁體中文使用 `zh` 字串，其餘（English / Deutsch / Español）目前顯示英文。
